# Obtaining BNL GitHub Enterprise Access

Membership in the [`BNL-Genesis`](https://github.com/BNL-Genesis) GitHub
organization requires a **BNL GitHub Enterprise license**. Submit a license
request using the BNL ITD Service request form:

→ [BNL ITD Service Request](https://bnlprod.servicenowservices.com/sp?id=sc_cat_item&sys_id=88d2162e87d40e10562dfc09cebb35d1&sysparm_category=b78eb5ea87940e10562dfc09cebb3554)

Fill in the form as follows:

| Field | Value |
|---|---|
| **Requesting environment** | `GitHub` |
| **Existing Git environment** | `Yes` |
| **# of users being requested** | Number of licenses required |
| **Group or Organization** | GitHub Org `BNL-Genesis` |
| **Comments** | Project/Activity number to be charged, and the GitHub username of every user covered by the request |

## Next Step

A license does not by itself add your account to the `BNL-Genesis`
organization. Once the license is available, request organization membership:

→ [BNL-Genesis GitHub Workspace — Requesting Organization Membership](bnl-genesis-workspace.md#requesting-organization-membership)
