# BNL-Genesis GitHub Workspace

The BNL Genesis Mission GitHub workspace is the
[`BNL-Genesis`](https://github.com/BNL-Genesis) organization, hosted under
BNL GitHub Enterprise.

## Prerequisite: BNL GitHub Enterprise Access

Private and internal `BNL-Genesis` repositories are only accessible to
organization members, because BNL GitHub Enterprise does not allow outside
collaborators for this use case. Organization membership requires a BNL GitHub
Enterprise license.

If you do not have a license yet, follow:

→ [Obtaining BNL GitHub Enterprise Access](bnl-github-enterprise-access.md)

## Requesting Organization Membership

Once your license is available, request membership by opening an Issue in
this repository:

→ [Create a BNL-Genesis organization membership request](https://github.com/BNL-Genesis/support/issues/new?template=bnl-genesis-membership.md)

Provide the information required by the Issue template, including the GitHub
username(s) and the project or activity for which access is needed.
Organization administrators will review the request and grant organization
membership together with any repository access requested.

## Requesting Repository Access or Changes

To request access to an existing repository, or to change existing repository
access or configuration (for example, adding or removing users, changing
repository or team permissions, or transferring responsibilities to another
project member), open an Issue in this repository:

→ [Create a BNL-Genesis repository access request](https://github.com/BNL-Genesis/support/issues/new?template=bnl-genesis-repository-access.md)

Organization administrators will review the request and assign the appropriate
repository or team permissions.
